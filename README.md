# Global adiposity-associated disease risk, 2015–2050 — interactive results explorer

Static website (Leaflet + ECharts) presenting the study results: BMI exposure and
disease burden attributable to high BMI, at 0.1° grid resolution with national and
global time series (overall, by sex, by age group).

- Live site: served via GitHub Pages from this repository (branch `main`, root).
- Replication code: https://github.com/Eros-c/adiposity-burden-replication

Data files under `data/` (trend JSONs) and `maps/` (WebP overlays) are generated by
`code/s16_web_export/` in the replication repository.
